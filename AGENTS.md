# AGENTS.md — Dress Pattern

Python-генератор выкроек платьев на основе мерок. Веб-интерфейс на Streamlit, рендер выкроек в PDF и DXF.

## Стек

- **Python 3.10+**
- **Streamlit** — веб-UI
- **matplotlib** — рендер графики выкройки
- **shapely** — геометрия (полигоны, операции)
- **ezdxf** — экспорт в DXF (для раскройных плоттеров)
- **numpy** — расчёты

## Зависимости

```bash
pip install -r requirements.txt
```

Минимум: `streamlit`, `matplotlib`, `numpy`, `shapely`, `ezdxf`.

## Запуск

```bash
streamlit run app.py
```

По умолчанию открывается на http://localhost:8501.

## Структура

- `app.py` — единый файл со всей логикой (Streamlit + расчёты + рендер).
- Все данные мерок хранятся в `@dataclass Measurements` (`OG`, `OT`, `OB` и т.д.).

## Чего не делать

- ❌ Не коммитить `.env*`, секреты, файлы пользователей
- ❌ Не менять формулы расчёта выкройки без явного запроса — это технологические формулы, выверенные вручную
- ❌ Не использовать жёстко зашитые размеры — всё параметризовано через `Measurements`
- ❌ User-facing строки в Streamlit — только на русском

## Что делать при расширении

- Новые типы выкроек — отдельные функции рендера, общий слой `Measurements`
- Если файл становится > 1500 строк — разбить на модули (`measurements.py`, `render.py`, `export.py`, `app.py`)
- Для новых exports использовать существующий шаблон с `BytesIO` + `st.download_button`
