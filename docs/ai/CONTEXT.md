## Жёсткий архитектурный контракт

Параметрические выкройки **уже есть и остаются ядром**. Не заменять их AI-рисованием кроя.

```
мерки + (текст описания | фото референса)
  → OpenRouter → PatternSpec (JSON параметров модели)
  → существующий parametric drafting (ЕМКО/Мюллер)
  → SVG / PDF A4 tiled / DXF
```

- **LLM НЕ рисует** выкройку пикселями/SVG для кроя.
- AI только заполняет / предлагает параметры (`PatternSpec`).
- Каждая модель = параметрический шаблон + правила моделирования.
- Invalid `PatternSpec` → ошибка, не «ломаный» PDF.

## Стек

- **UI:** Streamlit (`app.py`)
- **Геометрия:** NumPy, Shapely (`buffer` для припусков)
- **Чертёж / превью:** Matplotlib
- **Экспорт:** PDF A4 tiled, SVG, DXF (ezdxf), внутренний JSON schema
- **LLM:** OpenRouter (openai-compatible), ключ `OPENROUTER_API_KEY` только из env
- **Валидация:** Pydantic (`PatternSpec`)
- **Язык UI:** русский

## Политика данных и AI

- **152-ФЗ не блокер** для мерок/фото в этом продукте (можно хранить).
- Секреты только в `.env*` — никогда в код / коммит.
- Логи LLM **без PII** (без мерок, ФИО, фото).
- Обещание «идеальная посадка с первого PDF без макета» — **вне скоупа**.

## Вне скоупа

Полный CLO/Lectra; своя соцсеть для швей; замена офлайн-коворкинга; AI-рисование кроя.

## Метрики (ориентир после P1)

- Доля PDF, дошедших до макета > 40%
- Правок на первый макет ≤ 2
- Стоимость OpenRouter на успешный PDF — мониторить
